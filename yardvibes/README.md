# Yard Vibes

Static site for the Dubai table. Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 4477
```

Then visit http://127.0.0.1:4477

Pages: Home, Hotbox, 7Heaven Sunday Dinner, and a booking note that copies to the clipboard for Instagram. The form stores nothing.

Address, hours, and a direct phone number are left off on purpose until they are confirmed in a reply. Public links used: [@yardvibesdxb](https://www.instagram.com/yardvibesdxb/), [@yardvibeshotbox](https://www.instagram.com/yardvibeshotbox/), and the [Linktree](https://linktr.ee/yardvibesdxb).
